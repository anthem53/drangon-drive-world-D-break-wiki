# 드래건 드라이브 월드 D 브레이크 공략 위키

게임보이 어드밴스(GBA) 게임 **드래건 드라이브 월드 D 브레이크**의 한국어 공략 위키입니다.

현재 GitHub Pages에서 운영 중입니다.

**[공략 위키 바로가기](https://anthem53.github.io/dragon-drive-world-D-break-wiki/)**

## 주요 내용

- 게임 모드와 전투 준비
- AP 시스템과 전투 방식
- 드래건 도감과 기술 목록
- 아이템과 변신 목록
- 능력치, 랭크업, 게놈과 진화
- 훈련장별 출현 드래건과 맵 안내

일부 입수처와 세부 조건은 확인 중이며, 해당 항목에 별도로 표시했습니다.
