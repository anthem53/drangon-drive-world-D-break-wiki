# 능력치와 대미지

## 능력치의 역할

드래건의 능력치는 총 8종입니다. STR부터 LUK까지의 역할은 게임 내 능력치 도움말을 바탕으로 정리했습니다.

| 능력치 | 한글 이름 | 역할 |
| --- | --- | --- |
| HP | 생명력 | 피해를 받으면 줄고 회복하면 늘어납니다. 전투 중 현재 HP가 0에 도달하면 쓰러집니다. 랭크별 능력치 표의 HP는 기본 최대 HP입니다. |
| STR | 완력 | 타격 계열 기술의 공격력에 영향을 줍니다. |
| VIT | 체력 | 타격 계열 공격을 받았을 때의 방어력에 영향을 줍니다. |
| INT | 지능 | 브레스와 탄 계열 기술의 공격력에 영향을 줍니다. |
| MNT | 정신력 | 브레스와 탄 계열 공격을 받았을 때의 방어력에 영향을 줍니다. |
| AGI | 민첩성 | 상대 공격을 피할 확률에 영향을 줍니다. |
| DEX | 기교 | 자신의 공격이 명중할 확률에 영향을 줍니다. |
| LUK | 행운 | 치명타 발생 확률과 카드·게놈 파츠 획득 확률에 영향을 줍니다. |

## 공격과 방어

타격 계열 기술은 공격자의 **STR**과 방어자의 **VIT**, 브레스·탄 계열 기술은 공격자의 **INT**와 방어자의 **MNT**가 공격력과 방어력에 관여합니다.

같은 공격을 기준으로 공격자의 **DEX**는 명중에, 방어자의 **AGI**는 회피에 관여합니다. HP의 일정 비율을 사용 조건으로 삼는 기술도 있습니다.

> 구체적인 대미지 계산식은 추가 확인이 필요합니다.
