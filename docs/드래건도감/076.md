| 항목 | 내용 |

| 도감 ID | 076 |
| 이름 | 후부키 스톰 |

| 종별 레벨 | Lv.3 |

종별 레벨은 종류별로 정해진 값이며, 아래의 랭크와 구분합니다.

## 드래건 설명

냉기를 쓰는 아라시 스톰의 변종. 캄파와 적대 관계에 있어 만나면 격렬하게 싸운다.

카드 설명을 정리한 문장입니다. 실제 전투 효과와는 구분합니다.
