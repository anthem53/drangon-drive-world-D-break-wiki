# 160 코알 S

![코알 S 카드 이미지](../assets/dragons/160.png)

## 기본 정보

| 항목 | 내용 |
| --- | --- |
| 도감 ID | 160 |
| 이름 | 코알 S |
| 일본어 이름 | コアルS |
| 속성 | 무(무속성) |
| 종별 레벨 | Lv.? |

종별 레벨은 종류별로 정해진 값이며, 아래의 랭크와 구분합니다.

`Lv.?`는 원본의 레벨 값이 FF(-1)인 특수 표기입니다.

## 드래건 설명

원본 카드 자료에 설명이 없습니다.
