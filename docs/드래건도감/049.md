## 드래건 설명

흑요석의 몸을 지녔다. 뿔을 칼처럼 휘둘러 공격한다. 잇토잔과 자웅을 겨룬다.

카드 설명을 정리한 문장입니다. 실제 전투 효과와는 구분합니다.
