## 드래건 설명

격투전용 인공 드래건. 바위처럼 꾸민 장갑을 지녔다. 충격을 잘 흡수해 피해에 강하다.

카드 설명을 정리한 문장입니다. 실제 전투 효과와는 구분합니다.
