# 구역별 출현 드래건

## 출현 조건 읽는 법

- **기본**은 해당 D 존이 열리면 별도 이벤트 플래그 없이 조우 후보가 되는 편성이다. 같은 드래건의 추가 편성은 해당 플래그가 켜져야 추첨 대상에 들어간다.
- **속성 포획 완료**는 6개 훈련장에서 해당 속성으로 잡을 수 있는 드래건을 모으는 조건이며, 플레이 기록에는 난입종도 포함된다. 엔딩 후에는 속성별 수집 조건이 풀린다는 플레이 기록이 있다. [속성 포획 플레이 기록](https://wazap.com/cheat/%E5%B1%9E%E6%80%A7%E3%82%B3%E3%83%B3%E3%83%97/23484/)
- **아키야마 대화 이벤트**는 해당 드래건에 관한 아키야마의 대화를 진행하는 조건이다. 메이오잔과 호코라이메의 선행 포획 대상은 ROM 대사로 확인했다. 나머지 8종의 세부 선행 조건은 미확인 상태이며, 표에 해당 ROM 플래그를 기재했다. 엔딩 후 해금은 플레이 기록을 따랐다. [지역별 조우 기록](https://drive.chottu.net/dragon_drive.html)
- **지형 ID**는 해당 드래건이 포함된 편성 중 적어도 하나를 받아들이는 맵 칸의 내부 번호다. 게임은 해당 칸에 편성의 모든 드래건이 출현할 수 있는지 검사한다. 같은 종이라도 랭크와 동행 드래건에 따라 실제 지형 조건이 달라질 수 있다.
- **Lv.**는 도감에 표시되는 종 자체 레벨이다. **랭크**는 편성 레코드에 들어 있는 출현 랭크다. 한 줄의 랭크와 지형 ID는 그 조건의 편성 전체에서 각각 합친 값이다.
- **난입**은 각 훈련장 전용 편성이다. 게임 내 대사는 일부 지역에서 여러 차례 전투하면 발생할 수 있다고 설명한다. 6곳의 난입 종과 편성 랭크는 ROM에서 확인했고, 정확한 전투 횟수나 확률은 확인하지 못했다. [난입 플레이 기록](https://wazap.com/cheat/%E4%B9%B1%E5%85%A5%E3%83%97%E3%83%AD%E3%82%B0%E3%83%A9%E3%83%A0%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6/15224/)

## ROM 검증 근거

- 기준 ROM은 `드래건드라이브_v36_이름입력음역.gba`이며 CRC32는 `884154A4`다. ID와 이름, 종 레벨, 속성은 [드래건 도감](../드래건도감/index.md)에 연결했다.
- 일반 조우 코드는 `0x0C4674`에서 시작한다. 조우 후보 포인터 표는 `0x2EA828`, 편성 포인터 표는 `0x2E7E00`이다. 조우 레코드는 12바이트이고 편성은 20바이트다. 편성의 드래건 ID·랭크 쌍은 `+3/+4`, `+5/+6`, `+7/+8`에서 읽었다.
- 지형 판정은 `0x0C4800` 일대에 있다. 맵의 칸 ID를 `0x2DDF00`의 마스크로 변환하고, `0x123AE8 + ID × 28 + 0x18`에 있는 드래건의 하위 4비트와 대조한다. 맵 칸 데이터는 `0x2E7E1C`부터 훈련장마다 192바이트다.
- 훈련장 개방 플래그는 `0x08CC5C`에서 기록하고 `0x08CC7C`에서 읽는다. 개방 시점은 아래 호출 위치와 원본 자료의 번역 대상 목록의 해당 시나리오 대사를 대조했다.
- 아키야마의 포획 단서는 대사 참조 `0x094408–0x09440C`와 `0x094494–0x094498`에 있다. 난입과 속성별 포획에 관한 설명은 `0x09458C–0x094590`, `0x094640`에 있다.
