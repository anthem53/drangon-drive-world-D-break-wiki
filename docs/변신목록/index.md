# 변신 목록

V36 ROM의 전투 변신 대상 선택 루틴을 기준으로 정리했다. **코알 계열**은 게놈 기록에 따라 변신 대상이 열리고, **치비**는 센코쿠라 형태의 획득 플래그를 확인한다.

## 코알 계열

게놈은 **색상(흰색·검은색)**과 **염기쌍(AT·TA·CG·GC)**으로 구분합니다. 내부 코드의 대응은 다음과 같습니다.

| 염기쌍 | 흰색 내부 코드 | 검은색 내부 코드 |
| :---: | ---: | ---: |
| AT | 1 | 5 |
| TA | 2 | 6 |
| CG | 3 | 7 |
| GC | 4 | 8 |

전체 코드 표는 [게놈과 진화](../육성시스템/게놈과진화.md#게놈-코드)를 참고하세요.

| 단계 | 해금 조건 | 변신 대상 |
| --- | --- | --- |
| 기본 | 처음부터 | [코알](../드래건도감/161.md) (161) |
| 1단계 | 게놈 기록 10개 이상 | [아에랄](../드래건도감/164.md) (164), [마레알](../드래건도감/163.md) (163), [아트랄](../드래건도감/162.md) (162) 중 하나 |
| 2단계 | 게놈 기록 20개 이상 | [알윈](../드래건도감/169.md) (169), [알 어비스](../드래건도감/167.md) (167), [알란더](../드래건도감/165.md) (165), [알셴](../드래건도감/168.md) (168), [알그란](../드래건도감/166.md) (166), [ID 170 형태](../드래건도감/170.md) 중 하나 |
| 3단계 | 게놈 기록 30개 이상이며 처음 30개가 모두 흰색이거나 모두 검은색 | [디 에러](../드래건도감/184.md) (184) |

1단계와 2단계의 형태는 아래 표대로 결정됩니다. **9번째와 10번째 기록의 염기쌍**을 확인하며, 이 두 기록의 색상은 구분하지 않습니다.

| 9·10번째 기록 | 1단계 | 2단계에서 흰색이 더 많을 때 | 2단계에서 검은색이 더 많을 때 |
| --- | --- | --- | --- |
| 둘 다 AT 또는 TA | 아에랄 | 알윈 | [ID 170](../드래건도감/170.md) |
| AT·TA 중 하나와 CG·GC 중 하나 | 아트랄 | 알란더 | 알그란 |
| 둘 다 CG 또는 GC | 마레알 | 알 어비스 | 알셴 |

2단계의 색상 다수결에는 **처음 19개 기록**을 사용합니다. 홀수 개를 세므로 동률은 없습니다. 3단계는 염기쌍 종류와 관계없이 **처음 30개 전체가 같은 색상인지** 확인합니다.

ID 170은 2단계 분기표에서 확인했다. 기존 한글 도감에는 이름이 없어 내부 ID로 적었다.

랭크 1 기준 최대 HP는 코알 2,000, 1단계 세 형태 5,000, 이름을 확인한 2단계 다섯 형태 8,000, 디 에러 8,800이다. 디 에러의 STR·VIT·INT·MNT는 각각 121이다.

ROM에서 확인한 조건은 각 형태의 획득 플래그다. 형태별 게놈 코드와 획득 경로는 추가 확인이 필요하다.

## 전투 중 사용

변신은 처음 제공받은 꼬마 드래곤들만 사용할 수 있으며, **소모 AP는 1**입니다. 변신 명령에서 형태를 선택하면 **싱크로나이즈가 강제로 시작**됩니다. 싱크로 수치가 일정 기준에 미달하면 **변신에 실패하고 턴도 소모**됩니다.

원본 자료의 mGBA 확인에서는 코알의 아트랄 변신 시도 뒤 싱크로 카운트가 7에서 6으로 줄었습니다. 형태별 싱크로 비용과 정확한 성공 기준은 추가 확인이 필요합니다.

변신 대상의 능력치와 보유 기술은 [드래건 도감](../드래건도감/index.md), 전투 중 행동은 [전투 방식](../전투시스템/전투방식.md)을 참고하세요.

## ROM 근거

- 대상 결정 루틴 `0x0874A8`, 게놈 코드 분류표 `0x127BB4`, 코알 형태 분기표 `0x127BD4`
- 10·20·30개 기록 시점 처리 `0x081E34–0x081E56`
- 치비의 센코쿠라 획득 플래그 조회 `0x0875C6–0x08760E`
