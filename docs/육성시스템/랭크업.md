# 랭크업

랭크업은 포획 가능한 드래건을 대상으로 이용할 수 있는 성장 시스템입니다.

## 경험치와 랭크 상승

드래건이 전투에 출전해 적을 쓰러뜨리면 경험치를 획득합니다. 랭크 성장이 적용되는 전투 정산에서 드래건 ID별 누적값에 보상이 더해지고, 다음 랭크 기준에 도달하면 랭크가 올라갑니다. 랭크는 1~5단계입니다.

같은 보상 EXP는 능력치 편집용 공용 EXP에도 별도로 더해집니다. 랭크가 오를 때 랭크 누적값이나 공용 EXP를 차감하지 않습니다.

정산 코드는 현재 HP가 0인 드래건을 건너뜁니다. 모드별로 어떤 전투에 랭크 정산이 적용되는지는 추가 확인이 필요합니다.

## 랭크업 효과

랭크가 올라가면 기본 HP와 능력치가 달라지고 새로운 기술을 습득할 수 있습니다. 카드에 표시되는 종별 레벨은 유지됩니다.

## 다음 랭크까지 남은 값

다음 랭크의 누적 기준값에서 현재 누적값을 뺀 값입니다. 차이가 음수이면 0으로 표시하며, 랭크 5에서는 다음 랭크 수치를 표시하지 않습니다.

예를 들어 [고쇼라쿠린](../드래건도감/143.md)의 누적값이 300이면 랭크 3의 기준값 525까지 225가 남습니다.

| 랭크 | 누적 기준값 | 직전 랭크 기준 대비 차이 |
| ---: | ---: | ---: |
| 1 | 0 | — |
| 2 | 252 | 252 |
| 3 | 525 | 273 |
| 4 | 1,134 | 609 |
| 5 | 2,100 | 966 |
