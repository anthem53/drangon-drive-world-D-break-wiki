# 게놈과 진화

## 게놈 코드

게놈의 내부 코드는 색상과 알파벳에 따라 다음과 같이 대응합니다.

| 내부 코드 | 색상 | 알파벳 |
| ---: | --- | :---: |
| 1 | 흰색 | AT |
| 2 | 흰색 | TA |
| 3 | 흰색 | CG |
| 4 | 흰색 | GC |
| 5 | 검은색 | AT |
| 6 | 검은색 | TA |
| 7 | 검은색 | CG |
| 8 | 검은색 | GC |

## 게놈 할당과 최대 능력치

게놈을 할당하면 **할당한 게놈에 따라 최대 능력치가 증가**합니다.

늘어난 최대 능력치 범위에서 **EXP를 적용하여 능력치를 설정**할 수 있습니다.

## 변신 조건과의 관계

코알 계열은 게놈 기록에 따라 변신 대상이 해금되고 형태가 결정됩니다. 내부 코드 **1~4는 흰색**, **5~8은 검은색**에 해당합니다.

구체적인 해금 조건과 형태별 분기는 [변신 목록](../변신목록/index.md)을 참고하세요.
