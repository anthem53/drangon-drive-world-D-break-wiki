# 레벨과 랭크

드래건의 종별 레벨, 랭크, 능력치 편집용 EXP는 각각 별도로 관리됩니다.

| 항목 | 의미 | 성장과의 관계 |
| --- | --- | --- |
| 종별 레벨 | 카드에 Lv.1~5 또는 Lv.?로 표시되는 종별 값 | 같은 드래건 ID라면 랭크가 달라도 그대로 유지됩니다. |
| 랭크 | 같은 드래건 안의 1~5단계 | 랭크에 따라 기본 HP, 능력치와 기술 목록이 달라집니다. |
| 능력치 편집용 EXP | 전투로 모으는 공용 자원 | 랭크 누적값과 별도로 관리되며 공용 잔액 상한은 9,999입니다. |

`Lv.?`는 종별 레벨의 내부값이 FF(-1)인 특수 표기입니다.

## 같은 레벨에서도 달라지는 랭크

[고쇼라쿠린](../드래건도감/143.md)은 종별 Lv.1입니다. 랭크 1의 기본 HP는 2,200, 랭크 5는 4,400이며, 랭크가 올라도 종별 레벨은 Lv.1로 유지됩니다.

원본 자료에 따르면 랭크 2의 기술 목록에는 랭크 1에 없던 빅 태클(기술 ID 2126)이 포함됩니다. 드래건별 랭크 보유 기술은 각 도감 상세 페이지에서 확인할 수 있습니다.

## 랭크 누적값과 공용 EXP

랭크 성장이 적용되는 전투 정산에서는 같은 보상 EXP가 공용 EXP 잔액과 드래건 ID별 랭크 누적값에 각각 더해집니다. 다음 랭크 기준에 도달하면 랭크가 상승하며, 이때 누적값이나 공용 EXP를 차감하지 않습니다.

원본 자료가 인용한 플레이 기록에서는 능력치 편집으로 능력치를 올리면 공용 EXP를 쓰고, 내리면 돌려받는다고 설명합니다. 이는 ROM으로 확인한 전투 정산 결과와 구분되는 플레이 기록 기반 정보입니다.
