# 특수·테스트 기술

[기술 목록으로 돌아가기](index.md)

동일한 이름도 슬롯별 AP와 효과가 다를 수 있어 각각 수록했습니다. 위력·효과값은 실제 HP 피해량이나 회복량이 아닌 원시값입니다.

> 테스트용 슬롯을 포함합니다. 일반 플레이에서 사용 가능한 기술 목록으로 해석하지 않습니다.
