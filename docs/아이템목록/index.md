# 아이템 목록

D 파츠 16종과 전투 아이템 카드 14종, 총 **30종**을 이미지와 함께 수록했습니다.

## 분류별 목록

| 분류 | 수록 수 | 사용 방식 |
| --- | ---: | --- |
| [D 파츠](D파츠.md) | 16 | 드래건에게 장착 |
| [전투 아이템 카드](전투아이템카드.md) | 14 | 전투에서 사용, 블랭크는 게놈 코드 입력에도 사용 |

각 목록에서 한국어·일본어 이름, 카드 이미지, 게임 설명과 효과를 볼 수 있습니다. 이미지는 원본 카드 그림과 팔레트를 복원한 64×64 PNG입니다.

## 자료 기준

V29 ROM 기반 아이템목록.md의 한국어 이름·설명과 수치 효과를 반영했습니다. 아이템 ID 0은 이름과 설명이 비어 있어 제외했습니다.

- 아이템 레코드: `0x2DF7BC`부터 40바이트 간격
- 효과 대조 테이블: `0x1250C8`
- 지속 시간, 상태 이상 부여 확률, 일부 특수 효과의 적용 범위와 입수처는 추가 확인이 필요합니다.
