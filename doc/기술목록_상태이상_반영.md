# 기술 목록과 상태 이상 반영

- 전투기술전체데이터.md의 이름 있는 702슬롯을 8개 분류 페이지로 구성했다.
- 전투기술목록.md의 한글 도움말을 슬롯 번호로 대조·조합했다.
- 기술목록/.pages의 nav에는 index.md만 지정하여 사이드바에 하위 기술 페이지가 나열되지 않도록 했다. 분류별 접근은 목록 페이지에서 제공한다.
- 상태 이상 5종, 해제·예방 3항목과 능력 저하 효과 10항목을 반영했다. 능력치 수치와 계산 관련 페이지는 수정하지 않았다.
- 상태 이상 대표 기술과 해제 기술은 슬롯 기준으로 상세 기술 항목에 연결했다.
- 드래건별 기술 연결은 별도 추출 후 반영한다.
