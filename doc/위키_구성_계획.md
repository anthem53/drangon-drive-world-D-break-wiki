여러 원본 파일에 흩어진 이름, 설명, 수치, 이미지와 관계 정보를 대조·조합하여 위키 항목별 데이터를 구성한다. 필요한 필드와 데이터 간 관계를 정의하고, 기존 자료에 없는 목록이나 설명은 확인 가능한 근거를 바탕으로 새로 작성한다. 부족하거나 충돌하는 정보는 확인 과제로 남긴다.

| 위키 항목 | 우선 확인할 자료 |
| --- | --- |
| 드래건 도감 | 드래곤목록.md, 드래건카드목록.md, 드래건랭크별능력치.md, image/ |
| 전투 시스템 | 드래건속성특징.md, 전투상태이상목록.md, 번역대상목록.md |

위 표는 재구성에 사용할 원본 자료의 조사 시작점이다. 자료의 실제 범위와 식별 기준을 확인한 뒤 중복과 충돌을 정리하고, 위키에서 사용할 이름과 표기를 통일한다. 재구성한 데이터는 원본 파일과 식별 번호 등 근거를 추적할 수 있도록 기록한다.

완료 기준: 위키 항목별 데이터 구성과 필드, 조합 기준, 출처 및 미확인 사항이 정리되고 첫 상세 페이지에 사용할 데이터가 구성되어 있다.

## 3. 드래건 상세 페이지 한 개 작성

자료와 이미지의 대응이 명확한 드래건 하나를 선정하고 실제 데이터로 공통 형식을 정한다.

- 이름과 식별 번호
- 이미지, 속성과 설명
- 랭크별 능력치
- 사용 기술과 관련 페이지 링크

- 출처와 확인이 필요한 사항

자료가 없는 항목은 추정값으로 채우지 않는다. 공통 설명은 관련 페이지로 연결한다.

완료 기준: 실제 데이터와 이미지가 반영된 상세 페이지 한 개를 검토하고 전체 도감에 적용할 형식을 확정한다.
